# Trabajo-6-Calculadora-de-sistemas-de-coordenadas-en-Java
Trabajo 6 para CV - Calculadora de Sistemas de Coordenadas

Creadores: Hernández Morales Anahí López Ibarra Padilla Sebastián Martínez Ruiz Josué Ignacio Román Ruiz María Celeste

Descripción: Es una calculadora con interfaz gráfica que convierte coordenadas en 2D y 3D, como de rectangulares a polares, cilíndricas y esféricas, y calcula distancias entre puntos. Utiliza validaciones con try catch para evitar errores de entrada y hace uso de Math.atan2 para identificar el ángulo correcto dependiendo del cuadrante. 

Información Adicional: El usuario inicia en un menú de selección general, escoge si desea convertir coordenadas o medir distancias, selecciona el sistema de origen y destino, ingresa los componentes numéricos validados paso a paso en ventanas emergentes, y obtiene la respuesta en pantalla con la opción de repetir la operación de inmediato o regresar al menú anterior.
